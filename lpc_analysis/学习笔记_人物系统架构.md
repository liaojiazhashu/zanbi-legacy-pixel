# LPC 人物系统架构（sheet_definitions 学习笔记）

> 来源：sheet_definitions/body/body.json —— 这是理解"像素人物完整设计维度"的权威范例。

## 一、LPC 人物的 5 大设计维度

一个像素人物 = **体型 × 动作 × 方向 × 图层 × 颜色** 五维组合。

### 1. 体型维度（6 种，body 层 layer_1 定义）
- `male` 成年男 / `muscular` 肌肉男 / `female` 成年女 / `pregnant` 孕妇 / `teen` 青少年 / `child` 儿童
- 每种体型是一套独立的 body base 图形（光头+紧身衣+无五官），按体型改变**身体比例**（肩宽/腰臀/身高/头身比）。

### 2. 动作维度（17 种动画，animations 字段）
`spellcast`施法 / `thrust`突刺 / `walk`行走 / `slash`斩击 / `shoot`射击 / `hurt`受伤 / `watering`浇水 / `idle`站立 / `jump`跳跃 / `run`奔跑 / `sit`坐 / `emote`表情 / `climb`攀爬 / `combat`战斗 / `1h_slash`单手斩 / `1h_backslash`单手反斩 / `1h_halfslash`单手半斩。
- 每个动作 = 一组多帧动画（如 walk 4 帧、run 6 帧、idle 4 帧）。
- **规律**：idle 是所有动作的"基准帧"；walk/run/jump 是移动类（腿摆动）；slash/thrust/shoot 是攻击类（手臂挥动）；hurt/sit/emote 是状态类。

### 3. 方向维度（4 方向，每帧 64×64 的 sheet 布局）
每帧 sheet 128×256 = 4 列（帧）× 4 行（方向），方向顺序：**row0=上(背对)、row1=左、row2=下(面向观众)、row3=右**。
- 向下（面向观众）是最常用基准方向。

### 4. 图层维度（zPos 层级，多层叠加）
- `body` zPos=10（最底层，光头身体）
- 往上：`legs`（裤/裙）→ `torso`（上衣）→ `head`（头饰/眼镜）→ `hair`（头发）→ `eyes`（眼睛，最顶层）
- 每层独立图形+独立调色板，叠加成完整角色。

### 5. 颜色维度（recolors 换色系统）
- 每层用 `recolors.material`（body/hair/cloth/metal/eye/fur）声明材质，`palettes`（ulpc/lpcr/all.lpcr）声明调色板来源。
- 一份图形 + 调色板 JSON = 22 肤色/27 发色/25 布料色变体，无需重画。

## 二、核心设计方法（可迁移到任何像素人物）

1. **先做"体型库"**：6 种体型各画一套 body base（光头+无五官），只变身体比例。
2. **再叠"服装库"**：legs/torso 各自独立，按体型适配（每层有对应体型版本）。
3. **最后叠"特征库"**：hair/eyes/头饰，同样按体型适配。
4. **动作 = 逐帧动画**：每个动作画多帧（idle 4/walk 4/run 6），帧间只有肢体摆动差异。
5. **换色 = 调色板替换**：同图形改色相，不重画。

## 四、6 体型身体比例实测（body base 向下帧，64×64 内 bbox）

| 体型 | bbox | 宽 | 高 | 宽高比 | 形状特征 |
|------|------|-----|-----|--------|----------|
| male 成年男 | (17,32)-(46,61) | 30 | 30 | 1.00 | 宽肩倒三角，腰略收 |
| female 成年女 | (18,34)-(45,61) | 28 | 28 | 1.00 | 窄肩圆润，腰明显收，臀圆 |
| child 儿童 | (20,38)-(42,61) | 23 | 24 | 0.96 | 头大（约占1/3身高），身短粗 |
| muscular 肌肉男 | (16,32)-(47,61) | 32 | 30 | 1.07 | 肩最宽+胸肌厚实+手臂粗 |
| pregnant 孕妇 | (18,34)-(45,61) | 28 | 28 | 1.00 | 腹部圆鼓凸起 |
| teen 青少年 | (18,34)-(45,61) | 28 | 28 | 1.00 | 肩窄单薄，身修长 |

**体型设计四要素**（决定体型差异的核心）：
1. **肩宽**：muscular 32px > male 30px > female/teen/pregnant 28px > child 23px。
2. **腰线**：female 腰收最明显（沙漏），male 略收（倒三角），muscular 腰粗（躯干厚）。
3. **头身比**：child 头最大（约占 1/3 身高），adult 头约 1/4，teen 居中。
4. **躯干厚度/特殊形态**：muscular 胸肌隆起、pregnant 腹部凸起、female 臀圆。

**明暗表现法**：肩/胸/腹的隆起处用 `=`（亮色）表现，腰/颈内收处用 `-`（中暗）表现，轮廓用 `%`（描边）勾勒——体型差异靠**明暗分布**而非单纯轮廓线。

## 五、动作维度实测（male walk 4 帧）

- walk.png 是 4 帧×4 方向（每帧 64×64），4 帧循环构成行走动画。
- 行走帧差异 = **腿交替前后摆动 + 手臂交替摆动 + 身体轻微起伏**（帧1左腿前右腿后 → 帧2双腿并拢 → 帧3右腿前左腿后 → 帧4双腿并拢）。
- idle.png 是 4 帧×4 方向（每帧 64×64），4 帧循环 = 站立呼吸微动（身体 1-2px 起伏）。
- **关键规律**：动画帧数越少越经济（walk 4 帧够用），帧间差异只动肢体不动躯干主体。
