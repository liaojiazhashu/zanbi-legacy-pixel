# Tiny 16 系列多角色（16×16 职业差异化）

> 来源：Sharm/Evert Tiny 16 Expanded Character Sprites（800×800，CC0/CC-BY）。

## 一、全局共享 15 色调色板（关键发现）

16×16 系列多角色 = **整个 sheet 只 15 色**（+绿背景），不是每角色独立调色板：

| 用途 | 颜色 |
|------|------|
| 统一描边 | #140c1c(lum14) 深紫黑（比 LPC #271920 更暗） |
| 暗部（衣/发） | #442434(43) 暗紫棕 |
| 肤色暗/亮 | #854c30(86) → #d2aa99(177) |
| 棕/橙 | #854c30 → #d27d2c(137) |
| 布料蓝 | #30346d(55) → #597dce(123) |
| 金属/石 | #757161(112) → #8595a1(146) |
| 金色/高光 | #dad45e(204) |
| 纯黑（眼睛/细节） | #000000 |
| 红（伤害/心） | #d04648(99) |
| 米白高光 | #deeed6(232) |

## 二、多角色差异化 = 颜色分配（非新调色板）

- 6 个角色共享这 15 色，差异化靠"给每个角色分配不同颜色组合"（法师蓝 #30346d、战士棕 #854c30、金发 #dad45e 等）。
- 同一颜色可跨角色复用（描边/肤色/金属灰全局共用）。

## 三、动画与布局

- 每角色 4×4 网格 = 4 方向（下/上/左/右）× 4 动画（Stand/Walk/Strike/Hurt）。
- 装备/武器独立 sprite（心/盾/剑/箭），角色 sprite 与装备 sprite 分离，合成时才叠加。

## 四、小尺寸铁律（16×16，与 Zelda 一致）

1. 每材质 2 级明暗（暗+亮），不做 5-6 级。
2. 统一深紫黑描边（不是纯黑，纯黑留给眼睛）。
3. 全局共享调色板（15-16 色封顶）。
4. 五官只画眼睛（纯黑点）。
5. 装备/武器独立 sprite 可换装。

## 五、可迁移（《赞比的遗产》8 角色）

- 8 角色可共享一个「全局调色板」+ 每角色分配颜色组合差异化（比每角色 6 色独立调色板更统一）。
- 但 96×160 是 64px+ 尺寸，需 4-5 级明暗（不是 16×16 的 2 级）——折中：每材质 4 级明暗 + 全局描边 + 角色特征色。
