# 像素表情/情绪设计（眼睛的微变化）

> 来源：LPC eyes human adult 6 表情（default/anger/closing/sad/shame/shock）逐像素对比。

## 一、核心发现：表情 = 眼睛 2-6 像素的增减

LPC 眼睛 = 两个小「L/V 形」青色像素簇（虹膜 #5686ae + 高光 #57cee4），每眼约 15-20 像素。

6 种表情只靠**眼睑/虹膜的微小增减**实现（不重画整张脸）：

| 表情 | 像素变化 | 视觉 |
|------|---------|------|
| default 默认 | 基准 | 正常睁眼 |
| anger 愤怒 | -2px | 眯眼（上眼睑压 2px） |
| closing 闭眼 | -6px +4px | 眼睑闭合成一条缝 |
| sad 悲伤 | -2px | 眼睛变小下垂 |
| shame 羞愧 | -4px | 眼睛向下看（下睑遮） |
| shock 震惊 | -4px | 眼睛变化（放大/缩小） |

## 二、像素表情设计方法

1. **眼睛是表情的核心**（嘴/眉在 64px 以下尺寸常省略或极简）。
2. **表情 = 眼睑像素的压/抬**：
   - 愤怒/悲伤 = 上眼睑下压（删虹膜上方 2px）。
   - 闭眼 = 虹膜几乎全删，只剩 1 行眼睑缝。
   - 羞愧 = 下眼睑上抬 + 虹膜下移。
   - 震惊 = 虹膜缩小（瞳孔占比增大）。
3. **同套调色板**：所有表情用同一眼睛调色板（虹膜+高光 2-3 色），不换色。
4. **表情层独立**：LPC 把 eyes 做成独立图层，换表情 = 换 eyes 图层（身体/头发/衣服不动）。

## 三、可迁移（《赞比的遗产》）

- 8 角色立绘主要用 default（正常睁眼）+ 必要时 sad（悲伤，老年赞比葬礼）/anger（愤怒，克隆赞比质问）。
- 做表情变化时：改眼睛图层的像素，不重画整个角色。
- 老人（elderly）眼睛：瞳孔占比更大（老年瞳孔 42.9% vs 成年 40%），眼白更少。

## 四、与之前「五官只画眼睛」的统一

- 16×16 小尺寸：五官只画眼睛（1-2 像素点），表情几乎不可见，靠动作/姿态传达。
- 64px 尺寸：眼睛 15-20 像素（3 色），可表达 6 种表情。
- 96×160 立绘：眼睛更大（可到 20-30 像素），可表达更丰富表情（+眉毛+嘴）。
