# LPC 调色板系统设计方法（核心学习笔记）

> 来源：Universal-LPC-Spritesheet-Character-Generator 官方 palette_definitions/ + PALETTE_RECOLOR_GUIDE.md
> 这是像素人物「调色板设计方法」的权威范例。

## 一、系统架构

LPC 把颜色分成 7 大图层类型，每个类型有独立调色板定义：
`body`（肤色）/ `hair`（发色）/ `cloth`（布料）/ `cloth-metal`（金属布料）/ `metal`（金属）/ `eye`（眼睛）/ `fur`（毛皮）。

每个调色板 = 多个「变体 variant」，每个变体 = **固定 6 色数组**，按 **shadow→highlight 明暗渐进** 排列：
```
[描边/最暗, 暗, 中暗, 中, 亮, 高光/最亮]
```

**核心设计**：一个「基础图形」（如光头身体 base）只画一份，靠调色板 JSON 实时替换颜色，生成 22 种肤色/27 种发色/25 种布料色，而**不用画 22 张图**。这是工业级像素人物的「换色系统」标准做法。

## 二、统一描边规律（关键）

三种主材质的描边色几乎一致，都是**深紫棕**（lum 28-33），不是纯黑：
- body 描边 `#271920`（lum 33）
- hair 描边 `#260D14`（lum 21，偏红棕）
- cloth 描边 `#281820`（lum 28）
- 规律：**描边不用 #000000 纯黑，而用带色相的深紫棕**，让轮廓与材质融合；发色描边最暗（头发体积感强）。

## 三、肤色 body（22 变体 × 6 色）

最常用 `light` 浅肤（也是 base 默认）：
```
#271920 描边    (lum 33)
#99423c 暗      (lum 42, 红棕——肤色暗部偏暖红)
#cc8665 中暗    (lum 101)
#E4A47C 中      (lum 140)
#F9D5BA 亮      (lum 184)
#FAECE7 高光    (lum 204)
```
其他 21 变体（amber/olive/taupe/bronze/brown/black/blue/bright_green/dark_green/green/lavender/pale_green/zombie/zombie_green/fur_*×7）——覆盖人种/奇幻肤色/僵尸。

**关键规律**：
- 肤色暗部不是灰色，是**暖红棕**（#99423c），模拟皮下血色。
- 每级亮度跨度约 40-60 lum，形成 5 级清晰明暗。
- 奇幻色（蓝/绿/僵尸）同样保持「描边深 → 高光亮」的 6 级结构，只是色相变。

## 四、发色 hair（27 变体 × 6 色）

最常用 `orange` 橙（默认）：`#260D14 → #6A1108 → #A42600 → #BF4000 → #E55600 → #FF8A00`

关键变体（用于老年/白化/灰发）：
- `white` 白：`#1D1D21 → #484E57 → #8B9498 → #B8BBBC → #D8DCDC → #FFFFFF`
- `gray` 灰：`#0E0E0E → #292929 → #4B4B4B → #777777 → #AAAAAA → #D9D9D9`
- `dark_gray`：`#000000 → #0E0E0E → #1B1B1B → #3B3B3B → #7C7C7C → #C1C1C1`
- `platinum` 白金：`#1C0E06 → #7D5D5D → #A87D52 → #C0AB81 → #EDDF95 → #F6F6F3`

其他：ash/blonde/sandy/strawberry/gold/ginger/carrot/redhead/red/light_brown/chestnut/dark_brown/black/raven/rose/pink/purple/violet/navy/blue/green。

**关键规律**：
- 白发（white）描边是 `#1D1D21`（深蓝黑），暗部 `#484E57`（蓝灰）——**不是纯灰，带蓝冷调**，这样白发才不显脏。
- 灰发（gray）是**纯中性灰**（无冷暖偏），用于老态。
- 发色暗部同样有明确色相（橙发暗部是红棕 #6A1108）。

## 五、布料 cloth（25 变体 × 6 色）

最常用 `white` 白（衬衫）：`#281820 → #4D4A5D → #958080 → #C4B59F → #E5E6C7 → #FFFFFF`

其他：brown/leather/walnut/yellow/tan/orange/rose/maroon/red/pink/lavender/purple/blue/navy/teal/bluegray/forest/green/sky/slate/gray/black/charcoal。

**关键规律**：
- 白色布料的暗部是 `#4D4A5D`（蓝灰）+ `#958080`（灰粉），**不是纯灰**——暖光下白布暗部偏暖。
- teal 青色：`#180716 → #1B2B47 → #0E4E72 → #156C99 → #0098B2 → #00CFDF`（女孩发带用的就是这套）。
- 布料色阶跨度比肤色更柔和（暗部到亮部 lum 28→255），因为布料反光弱。

## 六、设计方法总结（可迁移到任何像素人物）

1. **每个材质固定 6 色**（1 描边 + 5 明暗），明暗按 lum 阶梯递增。
2. **描边统一深紫棕**（lum 21-33），不用纯黑；不同材质描边色微调（头发最暗）。
3. **暗部带色相**（肤色暗部暖红、白发暗部蓝灰、白布暗部蓝灰），模拟材质真实反光，避免"脏灰"。
4. **变体系统 = 同结构换色相**：22 肤/27 发/25 布，一份图撑起全部配色。
5. **每级亮度跨度 40-60 lum**，5 级明暗足够表现体积（像素人物不需要更多色阶）。
6. 应用：做 8 角色时，先定"材质→描边色→6 色明暗阶梯"，再按角色换色相变体。

## 七、眼睛 eye（8 变体 × **3 色**）

眼睛只用 3 色（小材质少色，够用）：
- `blue` 蓝：`#2a3c49`瞳孔(暗) → `#5686ae`虹膜(中) → `#57cee4`高光(亮)
- `green` 绿：`#2b4b29` → `#53b351` → `#84ec50`
- `purple`/`red`/`orange`/`yellow`/`brown`/`gray` 同理。
- **规律**：眼睛 = 瞳孔深色 + 虹膜中色 + 高光亮色；因为眼睛像素少（约 40px），3 色就能表现"瞳孔+虹膜+反光"三层；不做描边（眼白是肤色层的一部分）。

## 八、金属 metal（8 变体 × 6 色）

- `steel` 钢：`#1D131E描边 → #4D4A5D → #726B7E → #867E7F → #C4B59F → #FFFFFF高光`
- `gold` 金：`#2E2533描边 → #6D4A00 → #966600 → #DC6F35 → #FFC95A → #FFFF61高光(黄)`
- `silver` 银：`#1D131E → #31313E → #4A5057 → #818B8B → #D6E1D3 → #FFFFFF`
- `iron` 铁：`#000000 → #1B192B → #29253A → #343043 → #484152 → #726B7E`（**铁用纯黑描边**，暗沉无光泽）
- `copper` 铜：`#691503 → #7B2008 → #973C23 → #9D5427 → #EC855C → #FFC95A`
- `brass` 黄铜：`#1A1213 → #61482C → #836332 → #AF8A35 → #FDD082 → #FDF5CC`
- `ceramic` 陶瓷：`#181009 → #32251A → #594435 → #7D604D → #BA9069 → #FBE3B0`
- `bronze` 青铜：`#4F2313 → #6D4A00 → #966600 → #BF8200 → #E7A820 → #FBE3B0`
- **规律**：金属高光更亮（steel/silver 到纯白 #FFFFFF，gold 到亮黄 #FFFF61）；因为金属反光强烈，明暗跨度比布料大；唯一例外是 iron（铁）用纯黑描边+整体暗沉，表现无光泽铁质。

## 九、综合设计方法（最终版，可迁移）

| 材质 | 色数 | 描边 | 暗部特征 | 高光 |
|------|------|------|----------|------|
| 肤色 body | 6 | #271920 紫棕 | 暖红棕（血色） | #FAECE7 米白 |
| 发色 hair | 6 | #260D14 红棕 | 带色相 | 亮色 |
| 布料 cloth | 6 | #281820 紫棕 | 蓝灰/灰粉 | #FFFFFF 或彩色 |
| 眼睛 eye | 3 | 无描边 | 深瞳孔 | 亮虹膜高光 |
| 金属 metal | 6 | #1D131E（铁用纯黑） | 暗沉或色相 | 纯白/亮黄 |

**最终法则**：
1. 材质决定色数（眼睛 3、其他 6），小材质少色。
2. 描边统一深紫棕（lum 21-33），铁金属除外（纯黑）。
3. 暗部必带色相（暖红/蓝灰/灰粉），不用中性灰（除非刻意做灰发/老态）。
4. 高光亮度按材质反光强弱定（布料白、金属纯白/亮黄、肤色米白）。
5. 换色 = 换变体（同 6 色结构，改色相），不重画图形。
