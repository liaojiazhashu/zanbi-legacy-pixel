# 怪物/敌人角色像素设计规律

> 来源：Bevouliin spiky monster（CC0，矢量风但设计规律可迁移）+ LPC/OpenGameArt 综合。

## 一、怪物造型设计（与人类角色的核心差异）

| 维度 | 人类角色 | 怪物/敌人 |
|------|---------|-----------|
| 体型 | 头+躯干+四肢（直立） | 圆顶/兽形/球形（非人形） |
| 面部 | 眼睛+鼻+嘴（柔和） | 夸张特征（大嘴+尖牙+多眼） |
| 特征 | 发型/服装区分 | 尖刺/鳞片/触角/爪区分 |
| 配色 | 肤色+服装（低饱和） | 高饱和警戒色（金/绿/紫/红） |
| 氛围 | 亲和 | 恐怖/攻击性 |

## 二、怪物配色规律（spiky monster 实例）

- 主体金色 3 级明暗：#ddb260(主 lum181)/#ebd467(亮 lum209)/#b38b4e(暗 lum143)。
- 夸张元素独立色：白牙齿 #ffffff（恐怖核心）、灰金属尖刺 #d0d2d3/#929497（攻击性）、深棕鳞片 #594527（质感）。
- 高光白集中在：牙齿 + 眼睛 + 身体右上（光泽感）。

## 三、怪物设计四要素

1. **夸张的威胁特征**：尖刺（攻击）、大嘴尖牙（吞噬）、多眼（监视）、爪（抓取）。
2. **非人形轮廓**：打破头+躯干+四肢的直立结构，用圆顶/球/虫形。
3. **高饱和警戒色**：自然界危险色（金=毒、绿=毒液、紫=剧毒、红=血）。
4. **材质对比**：身体软质（3级明暗）+ 硬质件（尖刺/甲壳用金属灰独立色）。

## 四、可迁移到《赞比的遗产》

- 机械赞比（非人形机械）：金属灰蓝身体 + 发光青眼带（机械版"夸张特征"）+ 核心灯（发光高光）。
- 立方体（终极非人形）：黑色立方 + 青边发光（纯几何+发光）。
- 未来做敌人/NPC 怪物：圆顶身体 + 尖刺 + 大嘴尖牙 + 高饱和警戒色。
