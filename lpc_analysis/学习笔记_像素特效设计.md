# 像素特效（魔法/技能 FX）设计

> 来源：Mikodrak "2D Spell Effects"（10 特效，CC0，Blender 粒子+AE 后处理）。

## 一、特效分类（10 种）

1. fx1_blue_topEffect 蓝色顶部光环（buff/状态）
2. fx2_swordFire 剑火（武器附魔）
3. fx3_fireBall 火球（投射物）
4. fx4_sign_of_fire 火焰法阵（地面符印）
5. fx5_fire_scissors 火剪刀（交叉火刃）
6. fx6_eaterFire 吞噬火（持续燃烧）
7. fx7_energyBall 能量球（蓄力）
8. fx8_lighteningBall 闪电球（雷系）
9. fx9_rainOnGround 地面雨（范围）
10. fx10_blackExplosion 黑色爆炸（暗系）

## 二、核心认知（作者制作方法）

- **作者原话**：这些特效"mostly results of my early experimentations… created by preparing and exporting a very basic particle animation in Blender, and then passing it through AfterEffects… used mostly noises/distortions"。
- **关键洞察**：像素特效通常**不是手工逐像素绘制**，而是「粒子系统生成动画 → 导出 → 像素化/降采样 → 有限调色板量化」。特效的本质是**粒子的像素化表现**。
- 火焰 = 橙红粒子上飘 + 明暗闪烁；闪电 = 分叉白蓝线 + 高亮核心；爆炸 = 扩散碎片 + 烟雾暗部。

## 三、像素特效设计规律（可迁移）

1. **特效颜色语义化**：火=橙红(#ff6000→#ffb000)、雷=蓝白(#00f0ff→#ffffff)、毒=绿、暗=黑紫。
2. **发光核心 + 暗部衰减**：特效中心最亮（接近白），边缘暗（接近透明/黑）。
3. **逐帧变化大**（不像人物 idle 微动）：火焰每帧重排、爆炸每帧扩散。
4. **透明背景 PNG 层**：特效是"叠加层"，用 screen/add 混合模式叠加到场景。
5. **可程序生成**：火焰/闪电/爆炸都可用代码（粒子/噪声）生成——与"美术只能 DS 手写代码"约束契合（pixelfx 项目即 244 特效纯 JS 生成）。

## 四、可迁移（《赞比的遗产》）

- 戴森环崩塌（S14）= 爆炸特效（碎片扩散+烟+闪光）。
- 机械赞比"发光眼带/核心灯"= 发光核心（中心白+边缘青衰减）。
- 立方体"能量球/代码流"= 能量球特效（青白发光+粒子）。
- 矿坑/车间场景 = 火花/蒸汽粒子特效。
