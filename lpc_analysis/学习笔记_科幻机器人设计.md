## 二、机器人 sprite 设计要点（48×60，ASCII 观察）

```
    **************       <- 头顶亮色高光
    **************       
    ############         <- 头盔（深色包裹）
    ####----  ----####    <- 眼带（暗色凹陷/发光青）
    ############         
########**++++++++**###  <- 肩部+胸口核心灯（+++）
########**++++==++++**#  <- 胸口能量灯
########***************  <- 身体主体（蓝）
    %%%%%%%%   *********  <- 髋部
    #####   #####         <- 双腿（深色）
    #####   #####         
    ################      <- 脚
```

**机械角色设计四要素**：
1. **头盔包裹**：头部用深色描边+暗部包裹，露出眼带/面罩（区别于人类的裸露五官）。
2. **眼带发光**：眼睛不是"瞳孔+虹膜"，而是**一条发光的横条**（青色 #00f0ff），机械感的关键。
3. **胸口核心灯**：胸部中央一个亮色核心（+++），能量来源的视觉符号。
4. **关节分块**：身体不是连续肤色，而是分块盔甲（肩甲/胸甲/髋甲/腿甲），块与块之间用描边分隔。

## 三、科幻调色板设计法则（可迁移到机械赞比）

1. **描边用深蓝黑**（#1a202c），不用 LPC 的紫棕——金属/机械用冷色描边，有机物（皮肤/布）用暖色描边。
2. **发光色是灵魂**：机械/科技角色必有一个"发光色"（青 #00f0ff 或蓝），用于眼带/核心/能量线——这是科幻感的来源。
3. **主体用冷色**（蓝/灰），暗部偏蓝灰（#2d3748），不用暖色——金属反光冷，皮肤反光暖。
4. **警示色点缀**：品红 #ff007f 或黄 #ffb300 少量点缀（1-3%），用于危险/能量标记。
5. **明暗对比强**：金属明暗跨度大（描边 lum32 → 高光 lum255），比布料的 5 层明暗更锐利。

## 四、与《赞比的遗产》8 角色的对应

- **机械赞比**（第三幕机械体）：用本笔记的机器人方案——深蓝黑描边 + 蓝主体 + 青眼带 + 胸口核心灯。
- **立方体**（最终形态）：黑立方体 + 青色边（发光青 #00f0ff 描边，呼应机械赞比的能量色）。
- **克隆赞比**（第二幕）：LPC 肤色方案，但可加一点科幻元素（青眼或能量纹）。

## 五、换色系统实战教训（机械赞比复刻练习3）

用 LPC 肤色 6 色 → 金属蓝 6 色换色，两次迭代教训：

1. **暗部不能太暗**：肤色暗部 #99423c(lum60) 若换成 #2d3748(lum54)，脸部在纯黑背景上几乎不可见（modlens 读成"无头/头被裁掉"）。→ 换成 #4a5568(lum84) 后头部清晰可见。
2. **眼带就是机械的"脸"**：发光青横条（y35-37 横跨头部）取代传统五官——机械角色不需要画眼鼻嘴，发光眼带即面部识别特征（modlens 读成"visor"）。
3. **换色映射对照**（肤色→金属蓝）：描边 #271920→#1a202c、暗 #99423c→#4a5568（关键调亮）、中暗 #cc8665→#607da8、中 #e4a47c→#3b82f6、亮 #f9d5ba→#60a5fa、高光 #faece7→#93c5fd。
4. **机械细节三件套**：发光眼带（横条+上下深色描边包裹）+ 胸口核心灯（小方块发光）+ 关节分块线（膝/肘深色横线）。
5. 换色=像素级 color swap，不改图形结构，因此"图形库"和"调色板库"分离是像素美术工业化的核心。
