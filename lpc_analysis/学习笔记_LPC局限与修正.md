# LPC 模板局限与 8 角色修正要点（复刻练习2 核验教训）

> 来源：复刻练习 2（female_pigtails / male_balding / muscular_buzzcut 拼合 + modlens 核验）。

## 核心教训：LPC 默认组合在深色背景上的三大误读

modlens 核验三个拼合角色，一致暴露 LPC 模板的局限：

| 组合 | modlens 误读 | 根因 |
|------|-------------|------|
| male_balding（秃顶老人） | "humanoid demon + two flame horns + beard"（恶魔+火焰角+胡须） | 秃顶两侧橙红残发被读成"角"；暗脸阴影读成"胡须"；青色眼读成"发光" |
| female_pigtails（双马尾女孩） | "dark face + glowing cyan eyes + eerie/mysterious"（暗脸+发光眼+诡异） | base 脸中间调 #cc8665 在纯黑背景偏暗；青眼 #57cee4 发光感 |
| muscular_buzzcut（寸头肌肉男） | "shadowed face + glowing blue eyes + red scarf"（暗脸+蓝眼+红领巾） | 脖子阴影读成围巾；青眼发光 |

## 三大局限与修正

### 1. 脸部暗调（LPC base 肤色中间调 #cc8665 偏暗）
- LPC base 的脸用 #cc8665（中间调）+ #99423c（暗部阴影），在纯黑背景上显得"暗脸"。
- **修正**：8 角色脸部用更亮的肤色（#E4A47C 亮部为主 + #FAECE7 高光），减少阴影面积，让脸清晰可见。

### 2. 青色发光眼（LPC 默认 eye=blue #57cee4）
- LPC 的眼睛默认是青色系（#50d4ec/#57cee4），在暗脸上像"发光眼"。
- **修正**：8 角色眼睛用深棕/黑虹膜（#3a2a1a 深棕 + #1a1a1a 瞳孔），只有高光点用白色，不用发光青。

### 3. 秃顶残发被读成"恶魔角"（balding + 橙红发）
- balding 的橙红残发块（两侧各一块月牙形）在深色背景上被读成"角"。
- **修正**：老年赞比秃顶残发改银白/灰白（#e8e8f0/#c8c8d8/#a0a0b0/#787888/#505060 + 描边 #26262e），且残发设计成"自然月牙形"而非尖角。

## 背景修正
- LPC 模板背景是纯黑/透明，角色在纯黑背景上显得"诡异"。
- **修正**：8 角色立绘背景用深蓝灰（#1a1a2e 或 #2a2a3e），或加一个淡色圆形底，让角色与背景有层次区分。

## 法师创作练习教训（v1 误读 → v2 修正，综合创作反馈）

综合运用 LPC 技法（尖帽+长袍+6色调色板+法杖道具）创作法师立绘，暴露 3 个新误读：

| v1 误读 | 根因 | v2 修正（已验证） |
|---------|------|------------------|
| 长袍下摆读成"讲台/podium" | 下摆太宽太方正（宽22字符≈头宽2倍），与窄上身形成"头+讲台"分离 | 下摆平缓梯形展开（腰宽20→脚踝宽30，≤肩宽1.5倍） |
| 下摆褶皱读成"楼梯/阶梯" | 每隔一行一条通长竖暗线太规则 | 褶皱用断续错位暗像素（点缀式，非通长线） |
| 法杖宝石读成"十字旗/风向标" | 4px 菱形太小无法表现圆 | 宝石改 7×7 圆形带左上高光（dist≤2亮/≤5中/≤9暗） |

**v2 核验通过**：modlens 正确识别"紫色长袍法师 + 尖顶帽 + 点眼 + 深紫点状纹理长袍 + 棕色法杖 + 发光青色球体"。

**创作通用法则（新增）**：
1. 服装下摆（袍/裙）= 平缓梯形展开，宽度不超过肩宽 1.5 倍，否则读成"讲台/桌子"。
2. 布料褶皱 = 断续错位暗像素点缀，禁止通长规则竖线（读成"楼梯/栅栏"）。
3. 手持小物件（宝石/珠宝）= 至少 5-7px 圆形+高光，禁止 <5px 菱形（读成"十字/旗"）。
4. 长柄道具（法杖/长矛）= 竖直细杆（1-2px 宽）+ 顶端大物件，杆要延伸到角色脚底同高。

## 老年赞比创作教训（v1 误读成"女性" → v2 修正）

综合创作秃顶老人，v1 被 modlens 读成"elderly woman"（老年女性），暴露性别区分问题：

| v1 误读 | 根因 | v2 修正（已验证） |
|---------|------|------------------|
| 银白残发读成"盘发/bun"（女性发型） | 残发太宽（x14-33 各占一半），像盘发 | 残发只贴太阳穴/耳后（x13-16/x32-35 窄条），头顶中央 x17-31 大片肤色（头皮） |
| 西装下摆读成"裙/dress"（女性服装） | 下摆连体延伸到脚踝 y71 | 下摆到臀 y39 截止，y40 起分腿裤（中间分缝 O 线两条裤腿） |
| 嘴线读成"腮红/blush"（女性化妆） | 嘴线模糊 | 下巴加白胡子（y19-21），明确男性 |

**v2 核验通过**：modlens 正确识别"elderly male + white hair combed back + white beard + balding forehead + dark navy jacket + navy wide-legged trousers + dark red shoes"。

**性别区分法则（新增）**：
5. 男性老人 = 白胡子 + 秃顶（中央头皮+两侧窄残发），残发不能宽于 6px（否则读成"盘发"）。
6. 男性下装 = 分腿裤（上衣到臀截止+裤腿分开+中间分缝线），禁止连体到脚踝（读成"裙"）。
7. 男性面颊禁止模糊色块（读成"腮红"），用清晰嘴线+胡子表达。

## 少年赞比创作教训（截肢+拄拐表达）

综合创作少年（乱发+破衣+截肢拄拐），核验通过：modlens 识别"brown/ginger hair + pale/peach skin + dark brown tunic with buttons + one leg shorter/replaced(amputation) + thin cane/crutch for support"。

**截肢+道具表达法则**：
8. 截肢 = 残腿画到膝盖即停（短竖条），另一条腿画到脚，长度对比产生"一条腿短/假肢"视觉。
9. 拐杖 = 2px 粗**垂直**杆（禁止 1px 斜线，读成"斜坡"）+ 顶端横向握把 + 位于身体外侧（与身体留空隙）。
10. 补丁/纽扣 = 浅色小块点缀，读成"纽扣"可接受（都表达衣服装饰）。
