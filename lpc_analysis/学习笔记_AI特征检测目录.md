# AI 生成像素画特征检测目录（自检核心依据）

> 来源：aseprite-ai-artist rules/92-generated-art-tells.md（GitHub，with-pebbly）。
> 这是检测"机器感/不专业感"的完整清单，每条 = 一个特征 + 检测方法 + 修复方法。

## 核心结论

机器生成的像素画 = "像素画的照片"，不是"网格上的像素"。特征：软块、尺寸不均、数百近同色、斑点纹理、跟随轮廓的阴影、处处同密度。**在 1× 原生绘制不会产生这些，但任何引入外部/滤波像素的路径都会。**

## 关键阈值（By size）

| 尺寸 | 用色 | 孤立像素 |
|------|------|----------|
| 8px | ≤4 | 0（除眼） |
| 16px | ≤8 | ≤1 |
| 32px | ≤16 | ≤1/对象 |
| 64px | ≤32 | ≤2/对象 |

**通用**：off-palette 0、近重复对（ΔE<3）0、半透明 0、描边 ≥60% 单一色（每缺口可解释）或刻意无描边。

## 修复顺序（rule 7）

pitch/scale → palette → silhouette/light → clusters/banding → edges → details。
（先修边缘后修调色板会返工）

## 关键模板（最常犯的 4 个）

1. **枕形阴影 → 正确光照**：高光不居中，偏移到光源方向（左上），对侧画新月形暗影，中间过渡。
2. **色带 → 交错边界**：明暗边界不能直线贯穿 8px，每几像素错开一格，一段用 checker 过渡。
3. **彩屑 → 聚集**：散落的亮/暗单像素 → 聚成两个簇（亮簇+暗簇），跟随单一光源方向，保留 1 个刻意高光点。
4. **马赛克糊眼 → 手画眼**：深色眼睑行 1px + 巩膜 1px + 瞳孔 2px/眼 + 微笑（嘴角上扬），瞳孔位置决定视线方向。
