# Kenney 18×18 tile 风格学习笔记（与 LPC 对比）

> 来源：下载并分析 Kenney Pixel Platformer（CC0，260KB）的 tilemap.png（379×170 主地形 sheet）+ tilemap-characters.png（224×74 角色头像 sheet）。

## 一、两种像素人物设计哲学对比

| 维度 | LPC（Liberated Pixel Cup） | Kenney（Pixel Platformer） |
|------|---------------------------|---------------------------|
| 角色尺寸 | 64×64 完整身体 | 18×18 tile（地形）/ 头像 |
| 图层 | 分层叠加（base+legs+torso+hair+eyes） | 单层 tile，无分层 |
| 调色板 | 每材质独立 4-6 色，单角色 23 色 | 全 sheet 27-34 色，每物体 5-8 色 |
| 描边 | 统一深紫棕 #281820 | 描边随色相（深蓝灰/深红/深绿） |
| 饱和度 | 低饱和偏灰（暗部带色相） | 高饱和鲜艳（纯色块） |
| 高光 | 占比 1-7%，集中隆起处 | 占比高（白/浅色大量使用） |
| 明暗 | 5 层明暗阶梯 | 3-4 层（描边+主体+亮部+高光） |
| 用途 | RPG 完整角色（对话/行走/战斗） | 平台跳跃 tile（地形+头像 UI） |

## 二、Kenney 调色板规律（27 色，tilemap.png）

- **描边 3 色随材质**：#434a5f 深蓝灰（通用 7287px）、#6f3e43 深红（暖色物体 5113px）、#7e3125 深红棕（皮肤/木质 559px）、#345551 深青绿（草地 1681px）。
- **草地 3 色**：#345551 深绿 → #2eb082 绿（4278px）→ #36e377 亮绿（830px）——绿色系饱和鲜艳。
- **肤色 4 色**：#cb815e 棕（9110px 最多）→ #e29f7b → #eea160 → #f4ac66 → #fcc782 高光——暖橙棕肤色。
- **蓝色系**：#1490c3 蓝 → #2cc5f6 亮蓝（2921px）→ #4ce5fd 青——高饱和天蓝。
- **高光**：#ffffff 白（1399px）、#dff6f5 浅青（1089px）、#f4cca1 米黄、#dce1e7 浅灰——明亮。

## 三、Kenney 18×18 头像设计法（tilemap-characters.png）

ASCII 观察（圆形头像，`@`描边 `%`暗 `*`主体 `#`深色五官 `+`高光）：
- 18×18 内画**圆形头部轮廓**（描边勾圆，四角留空）。
- 眼睛 = 两个深色点/小块（`##`），位置在脸中部偏下。
- 嘴巴 = 一条短线或点（`-`），在眼下方。
- 主体 = 单一肤色铺满圆内。
- 高光 = 头顶/脸颊亮色点。

**极简原则**：18×18 只够表现"圆形头 + 两个眼睛点 + 一个嘴"，靠**颜色区分角色**（不同肤色/发色/帽子色），不靠细节。

## 三之补充：Kenney Roguelike 16×16 完整人物（roguelikeChar_transparent.png）

- 918×203 sheet，78 色（比 Pixel Platformer 27 色多——含大量灰渐变+棕/绿/青/紫多材质）。
- **16×16 人物 ASCII**（x=0 列，`=`亮 `:`中 `+`高光 `-`暗）：
  ```
       ======        <- 头顶（3行）
      =::::::=       <- 脸/头发
      =:=::=:=       <- 眼睛（2个暗点）
      =::::::=       
   ===::::::::===    <- 肩膀
  =::::::::::::::=   <- 躯干（6行）
  =::=::::::::=::=   <- 手臂两侧
   ===::====::===    <- 髋部
     =::=  =::=      <- 双腿
       ++++++        <- 脚
      +------+       
  ```
- **16×16 极简人物比例法则**：头 3/16（20%）+ 身体 8/16（50%）+ 腿 3/16（20%）+ 脚 1/16；眼睛=2 个深色点；手臂=躯干两侧伸出 1-2px；靠颜色区分角色。
- 与 LPC 64×64 对比：16×16 只有"头+身+腿"三段，无发型/衣物/明暗细节；64×64 可分层叠加完整发型+衣物+明暗。**尺寸每翻倍，可表现细节翻 4 倍（面积）**。

## 四、核心收获（可迁移到 8 角色设计）

1. **尺寸决定细节层级**：64×64 可做完整身体+分层+明暗；18×18 只能做头像/极简图标。8 角色用 96×160（介于两者，可做半身+明暗）。
2. **描边两派**：LPC 统一深紫棕（低饱和统一感）；Kenney 随色相（高饱和活泼感）。8 角色可选 LPC 统一描边（严肃科幻题材）或混合（角色描边统一+场景描边随色相）。
3. **饱和度两派**：LPC 低饱和（写实/严肃）；Kenney 高饱和（卡通/明快）。《赞比的遗产》科幻严肃题材选 LPC 低饱和更合适。
4. **高光占比**：LPC 克制（1-7%）；Kenney 明亮（高光大量）。8 角色取中间（5-10% 高光，比 LPC 略亮避免"暗脸"问题）。
5. **颜色区分法**：Kenney 靠"颜色块区分角色"（不同肤色/服装色）——这对 8 角色"独特性"要求（m03684）有启发：先定每个角色的主色，再设计细节。
